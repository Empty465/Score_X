**우주 쓰레기 수거 (원작: 스네이크 런)**

* **설정:** 궤도에 흩어진 파편이나 에너지 코어를 수거하는 소형 드론 조종.  
* **특징:** 수거할수록 꼬리(화물칸)가 길어져 조종이 까다로워짐.

**시스템 오류 복구 (원작: 짝꿍 찾기 / 메모리 게임)**

* **설정:** 태양풍으로 손상된 메인 시스템의 회로를 기억해내어 재부팅.  
* **특징:** 카드 대신 우주선 제어판의 홀로그램 아이콘(엔진, 산소통 등) 짝맞추기.

**수동 도킹 시퀀스 (원작: 타이밍/순간포착 게임)**

* **설정:** 자동 도킹 시스템 오류로 인해 우주선 결합부를 수동으로 타이밍에 맞춰 연결.  
* **특징:** 레이더 조준경 UI를 사용하며, 정확한 타이밍 클릭 시 묵직한 기계음으로 타격감 부여.

**비상 경고등 진압 (원작: 두더지 잡기)**

* **설정:** 선내 과부하로 곳곳에 켜지는 붉은색 비상 스위치를 빠르게 눌러 차단.  
* **특징:** 누르면 감점되는 '산소 배출 버튼'을 함정으로 배치하여 난이도 조절.

**궤도 진입 좌표 해독 (원작: 숫자 야구)**

* **설정:** 통신이 두절된 상태에서 궤도 진입을 위한 보안 코드(3\~4자리) 해독.  
* **특징:** 해커들의 녹색 터미널 창이나 함선 컴퓨터 콘솔 디자인 적용.

**1단 부스터 회수 (원작: 로켓 착륙 시뮬레이터)**

* **설정:** 사용된 발사체를 해상 바지선이나 화성 표면에 안전하게 수직 착륙시킴.  
* **특징:** 고도와 속도를 텍스트 HUD로 표시하여 현실적인 스페이스X 테마 강조.
