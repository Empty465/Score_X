# **🚀 \[Score X\] 게임 기획서 (Game Design Document)**

## **1\. 프로젝트 개요**

* **게임명:** Score X (스코어 엑스)  
* **플랫폼:** HTML 기반 웹 브라우저 게임  
* **장르:** 미니게임 컬렉션 / 아케이드  
* **테마:** 민간 우주 기업(SpaceX 모티브)의 AI 학습 데이터 수집  
* **개발 형태:** 각 미니게임을 독립된 모듈로 개발 후 메인 웹페이지에 통합

팀 브랜치·개인 TODO·코드 리뷰 규칙은 [팀 개발 가이드](./TEAM_DEVELOPMENT_GUIDE.md)를 참고하세요.

## **2\. 게임 스토리 및 세계관**

우주 탐사 기업 'Score X'는 AI 데이터 수집을 위해 테스트를 요청 합니다. 좋은 성과의 데이터를 제공하는 이에게 보상 제공을 약속했습니다. 하지만 그들은 추가적인 조건을 제시합니다. 보상을 바로 받아도 되지만, 해당 보상을 다시 자신들에게 투자하여 더 큰 보상을 받을 기회를 제공합니다.

## **3\. 핵심 플레이 모드**

**3.1. 미니게임**

* **자유 훈련 (Free Mode):** 원하는 미니게임을 선택하여 개별 점수를 기록하고 실력을 연습하는 기본 모드.

**3.2. 투자**

투자할 재화를 예치하고 저위험·균형형·고위험 옵션 중 하나를 선택하면 무작위로 구성된 3~5개 미니게임을 연속으로 플레이합니다. 투자 시작 후 첫 게임 시작 버튼을 누르고, 각 게임 결과를 확인한 뒤 투자 화면에서 다음 게임 시작 버튼을 눌러 진행합니다. 투자가 진행 중일 때는 투자 화면 또는 미니게임 화면에서 취소를 요청할 수 있으며, 별도 확인 후 투자금의 50%(소수 CR은 내림)를 환급받고 나머지는 손실 처리합니다. 모든 게임을 완료하면 확률표에 따라 `전액 손실`, `일부 손실`, `본전`, `소량 이득`, `대량 이득` 중 하나로 정산합니다. 미투자 상태로 게임을 완료하면 다음 투자 옵션을 다시 뽑을 수 있습니다.

## **5\. 시스템 및 개발 가이드라인**

### **5.1. 재화 및 랭킹 시스템**

* **미니게임 완료 보상:** 완료 결과에 해당 게임 점수와 획득 투자 재화를 함께 표시합니다. 획득 재화는 점수 100점마다 1 CR이며, 완료 시 최소 1 CR을 지급합니다.
* **최고 기록 점수판:** 각 미니게임에서 기록한 개인 최고 점수를 저장하고, 모든 게임의 최고 기록을 합산해 총 최고 기록 점수로 표시합니다. 이 합산 점수로 최고 기록 랭킹과 티어를 산정합니다.
* **투자 재화 점수판:** 현재 보유 중인 투자 재화(CR)를 별도의 점수판과 랭킹에 표시합니다. 투자·보상·상점 구매에 따른 잔액 변동을 반영하며, 최고 기록 점수와 합산하지 않습니다.

**5.1.1. 투자 재화**

주 획득 경로는 미니게임 완료 보상이며, 점수 100점마다 1 CR을 지급하고 게임 완료 시 최소 1 CR을 지급합니다. 사이트에 하루 1회 접속해 받는 출석 보상도 투자 재화 잔액에 더합니다.

**5.1.2. 재화 상점**

* 회원가입(아이디 4~20자 영문/숫자/_, 비밀번호 8~64자, 닉네임 2~16자)과 로그인을 지원합니다. 아이디·비밀번호는 화면에 표시하지 않으며 비밀번호는 scrypt 해시로 저장합니다.
* 로그인하지 않은 게스트로도 플레이할 수 있지만 점수·재화는 결과 화면에만 표시되고 저장·랭킹에 반영되지 않습니다.
* 가입 시 환영 재화 **500 CR**을 지급합니다. 재화 변동은 `credit_ledger` 원장에 기록되고 `wallets`가 잔액을 보관합니다.
* 서버 시작 시 구 버전(`users` 테이블) DB가 감지되면 기존 데이터를 폐기하고 새 스키마로 재구성합니다.
* 미니게임 점수 100점마다 **1 CR**을 지급하며, 게임 완료 시 최소 1 CR을 획득합니다.
* 닉네임 변경권(250 CR), 프로필 아바타(120~360 CR), 칭호(180~340 CR), 랭킹 배경(220~380 CR)을 구매할 수 있습니다.
* 닉네임은 로그인 아이디와 별도로 저장하며, 구매한 아바타·칭호·랭킹 배경은 프로필에서 언제든 다시 장착할 수 있습니다.
* 상점 꾸미기 아이템은 점수 및 랭킹 결과에 영향을 주지 않습니다.

**5.2. 랭킹** 

두 개의 점수판을 별도로 제공합니다.

1. **최고 기록 점수 랭킹:** 모든 미니게임의 개인 최고 기록 점수를 합산한 값으로 순위를 정하고, 합산 점수 구간에 따라 티어를 표시합니다. 반복 플레이 점수의 누적합이 아니라 게임별 최고 기록의 합입니다.
2. **투자 재화 랭킹:** 현재 보유 중인 CR 잔액이 많은 순으로 순위를 정합니다. 재화를 사용하면 잔액과 랭킹도 함께 변합니다.

랭킹의 플레이어 행에 마우스를 올리거나 터치하면 최고 기록 점수 랭킹은 미니게임별 점수를, 투자 재화 랭킹은 최근 투자 위험 옵션·정산 결과·순손익을 표시합니다.

두 점수판은 서로 다른 성과를 나타내며, 투자 재화 잔액은 최고 기록 점수나 티어 산정에 포함하지 않습니다.

최고 기록 합산 점수 티어는 **훈련생(0~999), 항해사(1,000~1,999), 개척자(2,000~3,499), 함장(3,500점 이상)** 순서입니다.

### **5.3. UI/UX 및 아트 디렉션**

* **기업 서비스 대시보드:** Score X의 공식 웹 서비스처럼 명확한 정보 구조와 일관된 카드·목록 UI를 제공하며, 게임 화면도 플랫폼 디자인과 자연스럽게 이어집니다.
* **디자인 에셋:** 다크 네이비 배경과 패널, 청록색 포인트, 경고용 레드, 가독성 높은 Noto Sans KR 본문 폰트와 수치용 DM Mono를 공통 디자인 기준으로 사용합니다.

### **5.4. 모듈형 개발 기술 지침**

* 메인 웹페이지(Shell) 개발자와 각 미니게임 모듈 개발자로 역할을 분담합니다.  
* **표준 API:** 미니게임은 sandbox iframe(`<scorex-game>` Web Component)에서 실행되며, 메인 페이지와는 함수 호출 대신 `postMessage`/`MessageChannel` 이벤트(시작 `init`: 난이도·seed·playId, 종료 `game_over`: 점수·플레이 시간)로만 통신합니다. 규격은 [MINIGAME_PROTOCOL.md](./MINIGAME_PROTOCOL.md)를 따릅니다.
* **핫플러그:** `games/<id>/manifest.json`과 `index.html`만 추가하면 메뉴에 자동으로 나타납니다. 점수는 서버가 발급한 playId로 검증합니다(최대 점수·최소 플레이 시간·중복 제출).
